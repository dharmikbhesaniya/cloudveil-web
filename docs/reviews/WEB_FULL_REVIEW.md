## 4. Public API Routes — Security Review (all four pass)

### `/api/track` — page-visit analytics
- **IP handling:** `x-real-ip` -> `x-forwarded-for`[0] -> `0.0.0.0` fallback, then
  **salted SHA-256, truncated to 32 hex chars** via `hashIp()`. Salt is
  `IP_HASH_SALT`; if unset, the whole IP column is **dropped** (fails safe).
- **Rate limited:** 60 req/min/IP via `checkRateLimit` (Redis) — previously the
  only public route with no limit.
- **Validation:** visitor_id/session_id/path required; visitor+session IDs
  sanitized with `[^\w-]` and truncated; every field length-capped.
- **Supabase write only** when `isSupabaseConfigured()`; otherwise 503.

### `/api/contact`
- Rate limited, required-field validation, length caps.
- `CONTACT_WEBHOOK_URL` delivery (JSON POST). **Referenced behavior: if omitted
  returns 503 and asks user to email support.**
- No SSRF: fixed env URL, no user-supplied host.

### `/api/waitlist`
- Rate limited, validated email, inserts waitlist row (server-only).

### `/api/md` (markdown renderer for AI crawlers)
- **SSRF closed:** only renders paths in `MARKDOWN_PAGES` allowlist
  (`/`, privacy, terms, refund, data-deletion, contact) resolved against
  `BASE_URL`. No arbitrary URL fetch. (This was the IS-007 fix.)
- Uses `turndown` to HTML->MD. Wrapped in a content-type header for consumers.

### Middleware
`src/middleware.ts` — rewrites to `/api/md` **only** when `Accept:
text/markdown` AND path in allowlist; otherwise passthrough. Clean.

## 5. Rate Limiting (`lib/redis/rate-limit.ts`)

Fixed-window limiter with two IS-007 fixes confirmed in code:
1. **Atomic key creation:** `SET NX EX <window>` — TTL set in the same call that
   creates the key (`redis.set(key, 0, { nx: true, ex: windowSec })` + `incr`).
   No INCR-then-EXPIRE race.
2. **Fails closed by default:** `failOpen` is an explicit per-call option,
   default `false`. Redis-missing/error => `{ allowed:false }`.

Plus belt-and-braces: if key exists without TTL, it gets one.

`lib/redis/client.ts` `getRedis()` returns null when Upstash env missing — every
caller must gate on `ioRedisAvailable`/`getRedis()`.
