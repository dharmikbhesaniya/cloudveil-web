## Why this task existed

The landing page used `Instrument_Serif` with `style: ["normal", "italic"]`,
which forced Next.js to download both optical files. The editorial emphasis
(`<i>` elements + `fontStyle: "italic"` across Navbar, Footer and section
components) looked dated against the new flat brand direction and added ~2
font files. Meanwhile the favicon was generated by two dynamic
`src/app/favicon/icon-192x192.png/route.ts` + `icon-512x512.png/route.ts`
handlers using a bare "I" monogram, and the repo carried six old brand-concept
PNGs that had already been superseded.

## What changed

### 1. Font load
- `src/app/layout.tsx` — `Instrument_Serif` now:
  ```ts
  style: ["normal"],   // normal only — italic optical files never fetched
  ```
- Removed `fontStyle: "italic"` from:
  - Navbar wordmark
  - Footer wordmark + tagline
- Removed `<i>`-based / italic serif emphasis inside:
  - HeroSection, ComparisonSection, PullQuote, CTASection, FeaturesSection,
    Stats

    serif-accent mechanism (`.cv-em`/`.cv-display` where present).
